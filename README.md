# Scout AI

Scout AI is an AI-powered buying assistant that helps users evaluate used consumer electronics listed on Facebook Marketplace.

## Features

- Upload Marketplace screenshots
- OCR text extraction
- AI-powered listing analysis
- Purchase Confidence Score
- Transparent recommendation engine

## Supported Products

- iPhone
- MacBook
- PlayStation
- Samsung Galaxy
- AirPods
- Apple Watch

## Technology

- React
- FastAPI
- EasyOCR
- Ollama
- Granite 3.2 Vision
- Python
