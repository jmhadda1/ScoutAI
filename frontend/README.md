# Scout AI Frontend

This folder contains the React frontend for Scout AI.

## Technology

- React
- Vite
- CSS

## Features

- Landing page
- Screenshot upload
- Loading screen
- AI results page
- Purchase Confidence Score

## Development

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

The frontend communicates with the FastAPI backend running on:

```
http://127.0.0.1:8000
```
